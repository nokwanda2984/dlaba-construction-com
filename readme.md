# DLABA Construction website

Responsive construction-company website with DLABA's charcoal, gold and white identity.

## Project files
- `index.html` — website content and categorized project gallery
- `styles.css` — layout, branding, responsive styling
- `script.js` — mobile navigation and WhatsApp enquiry form
- `assets/dlaba-logo.jpeg` — supplied company logo
- `assets/projects/` — supplied project photographs used in the gallery

## Run locally
1. Extract the ZIP.
2. Open this folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension.

Keep the `assets` folder alongside `index.html`; the image paths depend on this folder structure.

## Gallery categories
- House builds
- Renovations & interiors
- Paving & driveways
- Epoxy & floor finishes
- Parking & civil works

The gallery uses the photographs supplied in the project image ZIP. Some photographs show work in progress; captions describe the visible work and do not claim unverified project names or locations.

## Before publishing
Confirm company contact details, service descriptions, accreditations and all public-facing claims. Test the WhatsApp enquiry flow on desktop and mobile.
